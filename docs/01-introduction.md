# Introduction

## About SaniumTS Selenium Framework

SaniumTS is a modern, type-safe Selenium automation framework built with TypeScript. It combines design patterns, best practices, and developer-friendly features to make test automation simple and maintainable.

## Key Concepts

### Page Object Pattern
Encapsulates all UI interactions for a specific page in a dedicated class, separating test logic from page logic.

### Auto-Wait
Elements automatically wait for visibility and interactability before performing actions, reducing flaky tests.

### Auto-Retry
Assertions automatically retry within a timeout period, making tests more resilient to timing issues.

### Type Safety
Full TypeScript support with strict type checking ensures errors are caught at compile time, not runtime.

## Framework Philosophy

1. **Easy to Use** - Minimal setup, intuitive API
2. **Reliable** - Built-in wait and retry mechanisms
3. **Maintainable** - Design patterns and clean architecture
4. **Scalable** - Supports parallel execution and multi-browser testing
5. **Extensible** - Plugin architecture for custom implementations

## Technology Stack

- **TypeScript** - Type-safe JavaScript
- **Selenium WebDriver** - Browser automation
- **Mocha** - Test runner
- **Winston** - Logging
- **Allure** - Test reporting
- **Mochawesome** - HTML test reports
